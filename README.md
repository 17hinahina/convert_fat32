# convert_fat32

Windowsで大容量のSSD / USBストレージをFAT32にフォーマットするためのコンソールツールです。

Windows標準のフォーマット機能では、大容量ドライブをFAT32としてフォーマットできない場合があります。本ツールはその制限を回避し、最大約2TBまでのドライブをFAT32として初期化することを目的としています。

> [!WARNING]
> フォーマットを実行すると、対象ドライブ上のデータは失われます。重要なデータを必ずバックアップし、対象ドライブを十分に確認してから実行してください。

## Features

- Windows向けコンソールアプリケーション
- 最大約2TBまでのFAT32フォーマットを想定
- Windows標準の32GB FAT32フォーマット制限に依存しない
- 大容量SSD / USBメモリ / 外付けストレージ向け
- FAT32のBPB、FSInfo、FAT領域などを直接生成
- FATを2コピー作成
- FAT32バックアップブートセクタを作成
- ボリュームをロックしてからフォーマット処理を開始
- システムドライブの誤フォーマットを防止
- クラスタサイズを選択可能
- MBR環境ではFAT32 LBAパーティションタイプ `0x0C` を使用可能

## Supported Environment

- Windows 10 / 11
- x86-64
- 管理者権限が必要

一般的な512-byte logical sectorのドライブを主な対象としています。

## Supported Capacity

FAT32自体にはWindowsのGUIで表示される32GBというファイルシステム上の上限はありません。

本ツールでは、おおむね以下の範囲を対象としています。

| 項目 | 対応 |
|---|---|
| 小容量USBメモリ | Yes |
| 32GB超 | Yes |
| 64GB / 128GB / 256GB | Yes |
| 500GB / 1TB | Yes |
| 約2TB | Yes |
| 2TB超 | 非推奨 / 対象外 |

2TB付近では、パーティション方式、論理セクタサイズ、クラスタサイズ、接続先機器側の実装によって利用可否が変わる場合があります。

## Cluster Size

用途に応じてクラスタサイズを選択できます。

- 4KB
- 8KB
- 16KB
- 32KB
- 64KB
- Auto

大容量ドライブでは通常32KBクラスタを推奨します。

古い機器やDJ機器、組み込み機器などで使用する場合は、その機器が対応しているクラスタサイズを確認してください。

## Usage

### 1. EXEを管理者権限で起動

`FAT32SSDFormatter_console.exe` を右クリックし、**管理者として実行**します。

### 2. 対象ドライブを選択

接続されているドライブ一覧から、FAT32へ変換するドライブを選択します。

ドライブレター、容量、ボリューム情報を必ず確認してください。

### 3. ボリュームラベルを入力

必要に応じてボリューム名を入力します。

### 4. クラスタサイズを選択

通常は `Auto` または `32KB` で問題ありません。

### 5. 確認文字列を入力

誤操作防止のため、フォーマット直前に確認を要求します。

表示された対象ドライブが正しいことを確認してから続行してください。

### 6. フォーマット完了

処理完了後、一度ドライブを安全に取り外して再接続することを推奨します。

Windowsのプロパティ画面や `chkdsk` などで、ファイルシステムがFAT32として認識されていることを確認できます。

## Important Notes

### データはすべて消去されます

このツールはフォーマットツールです。

対象ドライブ上の既存データを保持したままNTFS / exFATからFAT32へ変換するツールではありません。

### システムドライブには使用しないでください

Windowsが起動しているドライブをフォーマットする用途ではありません。

### まず不要なUSBメモリ等で確認してください

ストレージへの直接書き込みを伴うため、本番用SSDで使用する前に、データの入っていないUSBメモリ等で動作確認することを推奨します。

### すべての機器での互換性を保証するものではありません

FAT32として正常にフォーマットできても、接続先機器側に以下のような制限がある場合があります。

- 最大ドライブ容量
- 最大パーティション容量
- MBR / GPTの対応状況
- クラスタサイズ
- 1ファイルあたりの最大サイズ
- ファイル数
- ディレクトリ階層

使用する機器の仕様も確認してください。

## FAT32 Limitations

FAT32では、1ファイルあたりの最大サイズが約4GBです。

そのため、4GB以上の単一ファイルを保存する必要がある場合はexFATやNTFSの方が適しています。

一方でFAT32は、古い機器、オーディオ機器、DJ機器、ゲーム機、組み込み機器などとの互換性が高いという利点があります。

## Partition Style

大容量ドライブを古い機器で使用する場合、GPTではなくMBRが必要になることがあります。

特に2TB以下のストレージをレガシー機器向けに使用する場合は、以下の構成が互換性の面で無難です。

```text
Partition style : MBR
Partition       : Primary partition
File system     : FAT32
Cluster size    : 32KB
Partition type  : 0x0C (FAT32 LBA)
```

ただし、最適な設定は接続先機器によって異なります。

## Why this tool?

WindowsではFAT32を読み書きできますが、標準GUIから大容量ボリュームをFAT32として新規フォーマットすることには制限があります。

そのため、例えば以下のような用途で不便が発生します。

- 64GB以上のUSBメモリをFAT32にしたい
- 1TB SSDをFAT32にしたい
- 2TB SSDをFAT32で使用したい
- exFAT非対応の機器で大容量ストレージを使用したい

`convert_fat32` は、この用途をシンプルなWindowsコンソールアプリで実行することを目的としています。
